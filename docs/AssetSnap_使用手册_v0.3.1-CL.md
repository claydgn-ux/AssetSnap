# AssetSnap 使用手册

> Release Identity：`AssetSnap_v0.3.1-CL`  
> Version：`0.3.1`  
> Owner：`CL`  
> 适用平台：macOS / Windows  
> 适用浏览器：Chrome / Edge + Tampermonkey

## 1. AssetSnap 是什么

AssetSnap 是一个 Tampermonkey 用户脚本，用于快速抓取网页图片。它可以在网页中识别可下载图片，优先尝试高清 / 原图来源，并根据设置保持原格式或转换为 JPG / PNG 后保存到浏览器默认下载目录。

v0.3.1 重点修复输入型网页上的快捷键使用问题：快捷触发键除了单个字母 / 数字，现在还可以设置为 `Shift`、`Alt / Option`、`Control / Ctrl`、`Meta / Command`。修饰键模式在 ChatGPT、搜索框、在线编辑器等页面即使仍有输入框焦点，也可以进入抓图状态。

v0.3.0 的可编辑命名前缀功能完整保留。

## 2. 安装

1. 在 Chrome 或 Edge 中安装 Tampermonkey。
2. 打开 `AssetSnap_v0.3.1-CL.user.js`。
3. 如果文件位于 GitHub，点击文件页面中的 **Raw**。
4. Tampermonkey 打开安装页面后，确认安装。
5. 打开普通网页，页面右侧应出现 AssetSnap 小胶囊。

如果 Raw 页面没有自动触发 Tampermonkey，也可以在 Tampermonkey Dashboard 中新建脚本，将 `.user.js` 全部内容粘贴并保存。

## 3. 快捷下载模式

默认快捷键仍然是：

```text
D + 左键点击
```

默认操作：

1. 将鼠标移动到目标图片上。
2. 按住 `D`。
3. AssetSnap 显示图片目标框以及可取得的尺寸 / 来源信息。
4. 按住 `D` 的同时左键点击图片。
5. 图片保存到浏览器默认下载目录。

### 3.1 支持的快捷触发键

快捷键设置支持：

- 单个英文字母，例如 `D`、`A`、`S`
- 单个数字，例如 `1`、`2`、`3`
- `Shift`
- `Alt`（macOS 显示为 `Option`）
- `Control`（Windows 常显示为 `Ctrl`）
- `Meta`（macOS 显示为 `Command`）

当前模式始终是：

```text
一个触发键 + 左键点击
```

本版本不提供 `Option + D + Click` 这类多键组合。

### 3.2 修改快捷键

1. 打开 AssetSnap 设置。
2. 找到“快捷键”。
3. 点击当前快捷键按钮。
4. 按一次想使用的字母、数字或修饰键。
5. 设置立即保存。
6. `Esc` 可取消快捷键修改。

如果按了不支持的键，AssetSnap 会提示允许的键类型，不会修改当前设置。

## 4. ChatGPT / 输入框页面推荐设置

在 ChatGPT、搜索页面、在线文档、编辑器等页面，光标经常停留在输入框中。

如果快捷键使用字母 `D`，按下 `D` 时网页会优先把它当作正常输入字符。这是“输入框保护”的预期行为：AssetSnap 不应抢走用户正在输入的字母。

解决方式是将触发键改为修饰键，例如：

### macOS

推荐优先尝试：

```text
Option + Click
```

或：

```text
Shift + Click
```

也可以选择 `Command`。`Control + Click` 在 macOS 可能被系统 / 浏览器当作辅助点击（类似右键），因此是否适合取决于实际输入设备和页面。

### Windows

可优先尝试：

```text
Alt + Click
Shift + Click
Ctrl + Click
```

某些浏览器或网站本身会占用特定修饰键 + 点击行为。如果一个键在某个网站冲突，直接换成另一个支持的修饰键即可。

### 4.1 为什么修饰键在输入框里仍能工作

v0.3.1 将输入保护分成两种行为：

- **字母 / 数字快捷键**：输入框有焦点时仍然被保护，不触发 AssetSnap。
- **修饰键快捷键**：即使普通网页输入框仍有焦点，也允许进入抓图状态。

AssetSnap 自己的设置面板仍受到保护，避免在修改设置时误触发抓图。

## 5. 连续下载模式

点击右侧 AssetSnap 小胶囊的主区域可以开启连续下载。

开启后：

- 不需要持续按住快捷键。
- 直接点击可识别图片即可保存。
- 胶囊会显示本次连续模式下的下载数量。

再次点击胶囊主区域或按 `Esc` 可退出连续下载模式。

## 6. 打开设置

点击 AssetSnap 胶囊右侧的下载图标打开设置面板。

当前可设置：

- 快捷触发键
- 图片来源：优先高清 / 原图，或当前显示图
- 输出格式：原格式 / JPG / PNG
- 同名文件处理方式
- 文件命名前缀
- 下载完成提示
- 输入框保护

设置通过 Tampermonkey 持久保存。

## 7. 修改文件命名前缀

设置面板中找到“文件命名”。

默认状态会显示：

```text
当前命名：AssetSnap    ✎
```

修改步骤：

1. 点击 `✎`。
2. 原位置变为输入框，按钮变为 `✓`。
3. 输入新的前缀，例如 `Harper`。
4. 点击 `✓` 或按 `Enter` 保存。
5. 按 `Esc` 可以取消本次编辑，恢复上一次已经保存的前缀。

编辑状态下会显示一个命名示例，帮助确认最终文件名结构。

## 8. 文件名规则

固定结构：

```text
<命名前缀>#yyyy-MM-dd_HH-mm-ss.ext
```

例如前缀为 `Harper`：

```text
Harper#2026-09-15_16-30-08.jpg
```

同一秒保存多张图片时：

```text
Harper#2026-09-15_16-30-08.jpg
Harper#2026-09-15_16-30-08_01.jpg
Harper#2026-09-15_16-30-08_02.jpg
```

其中：

- 用户只修改 `#` 前面的命名前缀。
- `#` 由程序固定添加。
- 日期时间由程序自动添加。
- 同秒序号 `_01`、`_02`……由程序自动添加。
- 扩展名根据最终实际保存格式自动决定。

### 8.1 命名前缀限制

命名前缀不能为空。

不允许：

```text
# / \\ : * ? " < > |
```

同时：

- 不能包含控制字符。
- 不能以点 `.` 开头。
- 前后不能带空白。
- 不能以点或空格结尾。
- 过长的名称会被拒绝，以降低跨平台文件名失败风险。

如果输入不合法，AssetSnap 会保留编辑状态并显示错误提示，不会覆盖已经保存的前缀。

## 9. 图片来源

### 优先高清 / 原图

AssetSnap 会尽量从以下位置寻找更高质量来源：

- `srcset`
- `<picture>` 中的 source
- 常见 `data-original` / `data-full` / `data-large` / zoom 等属性
- 图片外层直接链接到原图的地址

如果没有找到更高质量来源，则使用当前显示图。

### 当前显示图

只使用当前页面正在显示的图片地址。

## 10. 输出格式

可以选择：

- 原格式
- JPG
- PNG

如果选择 JPG / PNG，AssetSnap 会尽量先读取图片 Blob 并进行浏览器端转换。

如果转换不可用或失败，程序会优先保证图片能够保存，并尝试退回原格式。

JPG 转换时透明区域会以白色背景输出。

## 11. 下载结果提示

开启“下载完成提示”后，保存完成时会尽量显示：

- 缩略图
- 图片尺寸
- 文件大小
- 最终格式
- 高清原图 / 当前显示图
- 是否发生格式转换或转换回退

部分直接下载路径无法取得完整 Blob 信息时，尺寸或文件大小可能无法显示，但不代表下载失败。

## 12. 输入框保护

默认开启。

当光标位于网页的：

- input
- textarea
- select
- contenteditable

中时：

- 字母 / 数字快捷键不会触发 AssetSnap，避免干扰正常输入。
- 如果快捷键设置为 `Shift / Option / Alt / Control / Ctrl / Command / Meta`，修饰键仍可用于抓图。

关闭“输入框保护”后，字母 / 数字快捷键也可能在输入时进入抓图状态，因此通常建议保持开启。

## 13. 恢复默认设置

点击“恢复默认设置”后会恢复：

- 默认快捷键 `D`
- 优先高清 / 原图
- 原格式输出
- 默认同名文件策略
- 命名前缀 `AssetSnap`
- 下载完成提示开启
- 输入框保护开启
- 默认浮窗位置

## 14. 保存位置

AssetSnap 使用浏览器默认下载目录。

脚本不能直接指定任意 macOS / Windows 绝对保存路径。

如果浏览器自身开启“每次下载前询问保存位置”，浏览器仍可能弹出系统保存窗口。

## 15. 兼容与限制

- 支持 macOS / Windows。
- 目标浏览器为 Chrome / Edge + Tampermonkey。
- 当前快捷键为“单个触发键 + 左键”，不支持多键组合模板。
- 浏览器、操作系统或具体网站可能保留某些修饰键点击行为；冲突时请更换另一个触发键。
- 尚未加入站点专用适配器。
- 某些跨域、防盗链、授权图片或特殊网页实现可能限制原图读取。
- 格式转换属于 best-effort；失败时会优先保住下载结果。
- 只允许修改命名前缀，不提供完整命名模板、分隔符模板或自定义日期格式。
- 动画 GIF / 动画 WebP 没有专门的动画保留转换逻辑。

## 16. 从 v0.3.0 升级

直接安装 `AssetSnap_v0.3.1-CL.user.js` 即可。

v0.3.1 使用新的 `settings_v4` 设置存储，但会读取旧的 `settings_v3` / `settings_v2` / `settings_v1`。

升级后会继续保留：

- v0.3.0 的命名前缀
- 原快捷键
- 图片来源设置
- 输出格式
- 同名策略
- 下载提示开关
- 输入框保护
- 浮窗位置

如果之后把快捷键改成修饰键，新值会写入 `settings_v4`。
