# AssetSnap 使用手册

> Product ID：`AssetSnap`  
> Release Identity：`AssetSnap_v0.2.0-CL`  
> 类型：Tampermonkey Userscript  
> 适用平台：macOS / Windows  
> 当前目标浏览器：Chrome / Edge + Tampermonkey

---

## 1. 本版定位

AssetSnap 用于在网页中快速保存图片，核心目标是：

```text
找到图片
→ 尽量选择高清来源
→ 按用户设置尝试转换格式
→ 直接进入浏览器默认下载目录
→ 显示下载结果信息
```

AssetSnap 不管理 macOS / Windows 的任意绝对保存路径；保存位置由浏览器默认下载目录决定。

### v0.2.0 核心变化

- Tampermonkey 脚本列表直接显示：`AssetSnap · v0.2.0-CL`。
- 原来的大下载按钮、模式标签和 `···` 设置按钮合并成一个小型悬浮胶囊。
- 悬浮胶囊可以沿网页右侧上下拖动，并记住位置。
- 关闭连续模式时显示 `D + 点击`；打开后显示 `连续下载 · 数量`。
- 右侧小 `↓` 打开极简设置 Popover。
- 图片进入可下载状态后，Hover 信息会尽量显示：
  - `高清原图` / `当前显示图`
  - 目标图片分辨率
  - 如将发生转换，则显示 `WEBP → JPG` 等提示
- 下载成功提示改为小结果卡片，可显示：
  - 图片小缩略图
  - 分辨率
  - 文件大小（能够读取时）
  - 最终格式
  - `高清原图` / `当前显示图`
  - 实际发生的格式转换
- 新增输出格式：
  - `保持原图格式`
  - `统一转换为 JPG`
  - `统一转换为 PNG`
- 输出格式和其他用户设置使用 Tampermonkey 持久存储，跨网页保持上次设置。
- 格式转换失败不会阻止下载：AssetSnap 会退回原格式下载。
- 默认统一命名：`AssetSnap#yyyy-MM-dd_HH-mm-ss.ext`。
- 同一秒连续保存多张图时，自动生成 `_01`、`_02`……
- v0.1.0 的快捷键、图片来源、冲突策略、提示开关和输入框保护设置会继续读取；v0.2.0 新增设置在后续修改时写入新的设置版本。

## 2. 安装 / 更新

### 从 v0.1.0 更新

1. 打开 Tampermonkey Dashboard。
2. 找到旧版 AssetSnap。
3. 用 `AssetSnap_v0.2.0-CL.user.js` 的完整内容替换旧脚本。
4. 保存。
5. 刷新需要测试的网页。

更新后 Tampermonkey 列表应显示：

```text
AssetSnap · v0.2.0-CL
```

### 新安装

1. 安装 Tampermonkey。
2. Dashboard → 新建脚本。
3. 删除默认内容。
4. 粘贴 `AssetSnap_v0.2.0-CL.user.js` 全部内容。
5. 保存并启用。

脚本匹配：

```text
http://*/*
https://*/*
```

## 3. 默认操作

### 3.1 D + Click

默认连续模式关闭。

悬浮胶囊显示：

```text
○  D + 点击     ↓
```

操作：

1. 把鼠标移动到图片上。
2. 按住 `D`。
3. AssetSnap 识别目标图片并显示轻量边框和目标信息。
4. 左键点击。
5. AssetSnap 保存图片。

只按 `D` 不会下载；必须是 `D + 左键点击图片`。

### 3.2 连续下载模式

点击悬浮胶囊左侧区域即可切换。

开启后开关变绿，胶囊显示：

```text
● 连续下载 · 0     ↓
```

之后无需按 `D`，直接点击可识别图片即可保存。

成功保存后数字递增。

退出方式：

- 再次点击胶囊左侧区域；或
- 按 `Esc`。

---

## 4. 悬浮胶囊位置

悬浮胶囊默认位于网页右侧中部。

按住胶囊左侧区域上下拖动，可以改变纵向位置。

松开后 AssetSnap 会保存位置。之后刷新网页或打开其他网站，继续使用上次保存的位置。

右侧 `↓` 仅用于打开设置，不用于拖动。

---

## 5. 图片 Hover 信息

AssetSnap 进入可下载状态后，会在目标图片附近显示轻量信息。

例如：

```text
高清原图    3200 × 2400
WEBP → JPG
```

### 高清原图

表示 AssetSnap 根据网页提供的信息，选择了比普通当前地址更明显的原图 / 高清候选，例如：

- 图片直接链接
- `srcset`
- `<picture>`
- `data-original`
- `data-full`
- `data-large`
- `data-zoom-image`
- `data-hires`

这是 AssetSnap 对网页已有资源的选择，不代表 AssetSnap 能把低分辨率图片“变高清”。

### 当前显示图

表示本次使用当前网页实际显示的图片来源，或没有足够证据把目标标记为高清原图。

### 分辨率

能够读取目标图片尺寸时，会显示：

```text
3200 × 2400
```

特殊网站无法提前读取时，可能短暂显示：

```text
读取尺寸…
```

这不直接阻止下载。

## 6. 设置

点击悬浮胶囊右侧 `↓` 打开设置。

### 6.1 快捷键

默认：

```text
D + Click
```

点击快捷键项后，可以输入一个新的字母或数字。

支持：

```text
A-Z
0-9
```

### 6.2 图片来源

#### 优先高清 / 原图

AssetSnap 会检查网页提供的高清候选。

#### 当前显示图

只使用当前显示来源，行为更保守。

### 6.3 输出格式

提供三个选项：

```text
保持原图格式
JPG
PNG
```

#### 保持原图格式

例如原图是：

```text
WEBP → WEBP
PNG  → PNG
JPG  → JPG
```

#### JPG

AssetSnap 会尝试将能够读取和解码的图片重新编码为 JPG。

PNG / WEBP / AVIF 等带透明区域的图片转成 JPG 时，透明区域使用白色背景。

JPG 输出质量固定为当前版本的高质量默认值，不提供单独滑块。

#### PNG

AssetSnap 会尝试将能够读取和解码的图片重新编码为 PNG。

转换为 PNG 不会提升原图片的真实清晰度。

### 6.4 输出格式是否会记住

会。

例如选择：

```text
JPG
```

之后刷新网页、关闭并重新打开网页、访问其他网站，AssetSnap 仍使用 JPG，直到你再次修改或点击“恢复默认设置”。

这些设置属于 AssetSnap 脚本本身，不按网站分别保存。

正常版本升级也应继续读取已有设置；除非用户主动清理 Tampermonkey 的脚本存储或删除脚本数据。

### 6.5 同名文件

默认：

```text
自动加序号
```

AssetSnap 自己先通过时间命名和同秒 `_01 / _02` 降低冲突；如果 Downloads 中本来就存在同名文件，还会请求浏览器使用唯一文件名策略。

也可以选择：

```text
冲突时询问
```

最终冲突行为仍受浏览器 / Tampermonkey 下载模式支持情况影响。

### 6.6 下载完成提示

开启时会显示下载结果卡片。

关闭后不显示成功卡片；错误提示仍保留。

### 6.7 输入框保护

默认开启。

在以下区域输入文字时不触发快捷键：

- `input`
- `textarea`
- `select`
- `contenteditable`

## 7. 文件命名

v0.2.0 不使用网站原始文件名作为正式下载名。

固定基础规则：

```text
AssetSnap#yyyy-MM-dd_HH-mm-ss
```

例如：

```text
AssetSnap#2026-09-15_11-32-08.jpg
```

扩展名由最终实际保存格式决定。

### 保持原图格式

原图为 WebP：

```text
AssetSnap#2026-09-15_11-32-08.webp
```

### 统一 JPG

```text
AssetSnap#2026-09-15_11-32-08.jpg
```

### 统一 PNG

```text
AssetSnap#2026-09-15_11-32-08.png
```

### 同一秒下载多张

```text
AssetSnap#2026-09-15_11-32-08.jpg
AssetSnap#2026-09-15_11-32-08_01.jpg
AssetSnap#2026-09-15_11-32-08_02.jpg
```

当前版本不提供自定义命名模板编辑器。

## 8. 格式转换与失败退回

AssetSnap v0.2.0 的优先级是：

```text
第一：先把图片拿到
第二：尽量选择高清 / 原图
第三：按用户设置转换格式
第四：补充分辨率 / 文件大小 / 格式反馈
```

因此：

```text
用户选择 JPG
↓
读取 WEBP 成功
↓
转换 JPG 成功
↓
保存 JPG
```

下载结果会显示：

```text
WEBP → JPG
```

如果网站允许直接下载，但 AssetSnap 无法完成格式转换：

```text
尝试转换
↓
失败
↓
不取消下载
↓
保存原格式
```

结果卡片会显示：

```text
⚠ 转换不可用 · 已保留原格式
```

这条规则的目的，是避免新增格式转换功能反而降低原本能够下载的图片的成功率。

## 9. 下载成功结果卡片

成功时，AssetSnap 尽量显示：

```text
[缩略图]  ✓ 已保存        高清原图
          3200 × 2400 px · 2.41 MB · JPG
          WEBP → JPG
```

可能出现的信息：

- 小缩略图
- 分辨率
- 文件大小
- 最终格式
- `高清原图` / `当前显示图`
- 格式转换提示

如果最后只能交给浏览器直接下载，AssetSnap 可能无法知道最终字节大小，此时不会伪造文件大小。

---

## 10. 保存位置

AssetSnap 使用：

```text
浏览器默认下载目录
```

macOS 通常为 Downloads，Windows 通常为 Downloads，实际位置以浏览器设置为准。

如果希望改为 Desktop 或其他固定文件夹，请修改 Chrome / Edge 的默认下载目录。

如果浏览器开启：

```text
每次下载前询问保存位置
```

浏览器仍可能弹出保存窗口。

## 11. 当前图片识别范围

支持的主要路径：

- 普通 `<img>`
- `currentSrc`
- `src`
- `srcset`
- `<picture><source>`
- 常见 Lazy Load / 原图属性
- 图片外层直接图片链接
- CSS `background-image` 的第一张 URL
- 可导出的 `<canvas>`
- 内联 `<svg>`
- `data:`
- `blob:`

当前仍不保证：

- 跨域 iframe 内图片
- CSS `::before / ::after` 图片
- Closed Shadow DOM 内部资源
- DRM / 受保护媒体
- 强防盗链 / 特殊 Cookie / 特殊请求头站点全部成功
- 浏览器内部页面 `chrome://` / `edge://`
- 网站专用加密或一次性受保护资源

v0.2.0 不做 GIF / 动态 WebP 的专门动画保护逻辑。

## 12. 建议本轮重点测试

### A. Tampermonkey 版本显示

确认 Dashboard 中显示：

```text
AssetSnap · v0.2.0-CL
```

### B. 新悬浮胶囊

- 大小是否足够小巧
- 关闭状态是否显示 `D + 点击`
- 开启是否变绿并显示 `连续下载 · 数量`
- 上下拖动是否自然
- 刷新后位置是否保留

### C. JPG / PNG / WebP 普通图片

分别尝试：

```text
保持原格式
JPG
PNG
```

确认文件扩展名和实际打开结果正常。

### D. 设置持久化

1. 输出格式切换为 JPG。
2. 刷新当前网页。
3. 打开另一个网站。
4. 再打开 AssetSnap 设置。

应该仍为 JPG。

### E. 命名

确认下载名类似：

```text
AssetSnap#2026-09-15_11-32-08.jpg
```

同一秒快速下载多张时检查：

```text
_01
_02
```

### F. Hover 信息

检查：

- 高清原图 / 当前显示图
- 分辨率
- WEBP → JPG 等转换提示

是否与实际下载结果基本一致。

### G. 下载成功卡片

检查是否能看到：

- 缩略图
- 分辨率
- 文件大小
- 最终格式
- 高清状态
- 转换状态

### H. 转换失败退回

如果遇到一个特殊网站无法转换，请确认：

```text
转换失败
≠
整张图片下载失败
```

如果原图仍可以直接下载，应看到“已保留原格式”的提示。

## 13. 测试反馈建议

如果某个网站出现问题，请尽量提供：

```text
网站 URL
点击的图片截图 / 位置
当时的图片来源设置
当时的输出格式设置
AssetSnap 显示的错误或结果提示
实际下载得到的文件名 / 扩展名
```

如果 v0.2.0 出现 Bug，下一轮应先修复和回归对应路径，再继续增加新功能。
